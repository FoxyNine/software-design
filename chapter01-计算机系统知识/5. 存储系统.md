## 存储器

### 1. 知识点

存储器这块要会分类，不要混。  
最常考：

- **SRAM 构成 Cache**
- **DRAM 构成主存，且需要刷新**
- **虚拟存储器 = 主存 + 辅存**
- **相联存储器按内容访问**

| 名称       | 特点                 | 高频考法                 |
| ---------- | -------------------- | ------------------------ |
| SRAM       | 快、贵               | 构成 Cache               |
| DRAM       | 便宜、容量大、需刷新 | 构成主存                 |
| ROM        | 只读                 | 固化程序                 |
| 闪存       | 掉电不丢失、按块擦除 | 可替代 ROM，不可替代主存 |
| 相联存储器 | 按内容访问           | 不是按地址访问           |

### 2. 例题分析

**例 1**  
哪类存储器构成主存？  
**结论**：**DRAM**

**例 2**  
闪存能否代替主存？  
**结论**：**不能**，因为主存工作特点不同

**例 3**  
相联存储器按什么访问？  
**结论**：**按内容访问**

### 3. 记忆技巧

- 口诀：**主存 DRAM，缓存 SRAM，闪存掉电不丢**

## Cache 概念与关键性质

### 1. 知识点

Cache 是位于 CPU 与主存之间的高速缓冲存储器，本质上是**主存部分内容的副本**。  
目标不是扩大容量，而是**提高访问效率**。

| 判断项                                | 正误 |
| ------------------------------------- | ---- |
| Cache 是主存副本                      | 对   |
| Cache 主要目的是扩大主存容量          | 错   |
| Cache 越大命中率通常越高              | 对   |
| Cache 设置目的是提高 CPU 访问主存效率 | 对   |

### 2. 例题分析

**例 1**  
在 CPU 内外设置多级 Cache，主要目的是？  
**结论**：**提高 CPU 访问主存数据或指令的效率**

**例 2**  
以下关于 Cache 的叙述中，不正确的是“Cache 的设置扩大了主存容量”。  
**原因**：它提升的是速度与命中率，不是主存物理容量

### 3. 记忆技巧

- 一句话：**Cache 不扩容，只提速**

## Cache 与主存映射

### 1. 知识点

Cache 映射题非常高频，结论必须死记：

- **直接映像**：关系固定，冲突最多
- **全相联映像**：最灵活，冲突最少
- **组相联映像**：折中方案
- **Cache 与主存的地址映射由硬件自动完成**

| 映射方式   | 特点                        | 冲突情况 |
| ---------- | --------------------------- | -------- |
| 直接映像   | 简单、固定                  | 最多     |
| 组相联映像 | 折中                        | 较少     |
| 全相联映像 | 任意主存块可放任意 Cache 块 | 最少     |

### 2. 例题分析

**例 1**  
发生块冲突次数最少的是哪种映射？  
**结论**：**全相联映像**

**例 2**  
在程序执行过程中，Cache 与主存的地址映射由谁完成？  
**结论**：**硬件自动完成**

### 3. 记忆技巧

- 口诀：**冲突从多到少：直接 > 组相联 > 全相联**
- 看到“谁负责地址映射”，不犹豫，直接答 **硬件**
