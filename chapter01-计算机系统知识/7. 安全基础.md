## 公钥与私钥

### 1. 知识点

非对称加密也叫公钥体系。  
最容易混的只有两句：

- **用接收方公钥加密，用接收方私钥解密**
- **公钥加密是为了保密，私钥签名是为了认证/不可否认**

### 2. 例题分析

**例**  
公钥加密算法也称什么？  
**结论**：**非对称加密算法**

### 3. 记忆技巧

- 记忆：**保密看接收方，签名看发送方**

## 数字签名

### 1. 知识点

数字签名不是“给消息加密”那么简单，它主要解决：

- 消息是否被伪造
- 发送方能否否认

标准过程：

1. 发送方先对消息摘要做处理
2. **用发送方私钥签名**
3. 接收方**用发送方公钥验证**

| 目的           | 是否支持         |
| -------------- | ---------------- |
| 验证消息真实性 | 支持             |
| 防止发送方否认 | 支持             |
| 保密明文内容   | 不是它的主要职责 |

### 2. 例题分析

**例**  
数字签名的验证过程是什么？  
**结论**：**发送方私钥签名，发送方公钥验证**

### 3. 记忆技巧

- 口诀：**私钥签，公钥验，不可否认最关键**

## 数字证书

### 1. 知识点

数字证书解决的是“**你到底是不是你**”。  
核心角色是 **CA（证书授权中心）**。

标准过程：

1. 用户把身份信息和公钥提交给 CA  
2. CA 颁发数字证书  
3. **数字证书由 CA 私钥签名**
4. 用户通过 **CA 公钥验证** 证书真伪

| 对象     | 做什么                 |
| -------- | ---------------------- |
| CA 私钥  | 给证书签名             |
| CA 公钥  | 验证证书真伪           |
| 用户公钥 | 存在证书中，供他人获取 |

### 2. 例题分析

**例 1**  
某网站向 CA 申请了数字证书，用户通过什么验证什么来确定网站合法性？  
**结论**：**用 CA 的公钥验证 CA 的签名**

**例 2**  
确认用户身份通常使用什么？  
**结论**：**数字证书**

### 3. 记忆技巧

- 口诀：**CA 私钥签，CA 公钥验**
- 不要写反成“CA 私钥验证”

## 加密算法

### 1. 知识点

加密算法题本质上是分类记忆题。

| 类别       | 典型算法                       |
| ---------- | ------------------------------ |
| 对称加密   | DES、3DES、AES、IDEA、RC4、RC5 |
| 非对称加密 | RSA、ECC、DSA                  |
| 摘要算法   | MD5、SHA-1                     |

### 2. 例题分析

**例 1**  
AES 属于哪类算法？  
**结论**：**对称加密**

**例 2**  
RSA 属于哪类算法？  
**结论**：**非对称加密**

**例 3**  
MD5 的结果长度是多少？  
**结论**：**128 位散列值**

### 3. 记忆技巧

- 分类记忆：
  - **对称：DES、3DES、AES、IDEA、RC 系列**
  - **非对称：RSA、ECC、DSA**
  - **摘要：MD5、SHA-1**
