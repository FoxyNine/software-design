## 中断

### 1. 知识点

中断是运行中遇到紧急事件时，CPU 暂停当前程序，转去处理中断服务程序，处理完再返回原程序。  
本部分要抓 4 句话：

1. **中断向量提供中断服务程序入口地址**
2. **中断响应时间：从发出请求到进入中断服务程序**
3. **保存现场：为了正确返回原程序继续执行**
4. **中断与异常不同：外部请求通常叫中断，处理器内部特殊事件常叫异常**

| 概念             | 正确理解                   |
| ---------------- | -------------------------- |
| 中断向量         | 中断服务程序入口地址       |
| 保存现场         | 为了返回原程序             |
| 中断响应时间     | 请求发出到进入中断处理程序 |
| 多级中断保护现场 | 用堆栈最有效               |

### 2. 例题分析

**例 1**  
中断向量提供什么？  
**结论**：**中断服务程序入口地址**

**例 2**  
中断处理中保存现场的目的是什么？  
**结论**：**能正确返回到被中断程序继续执行**

**例 3**  
DMA 传送结束与除数为 0 分别属于什么？  
**结论**：前者通常看作**中断**，后者是**异常**

### 3. 记忆技巧

- 口诀：**向量给入口，现场为返回**
- 中断题很爱考“保存现场”，千万别误选“给中断程序提供数据”

## DMA

### 1. 知识点

DMA 是 Direct Memory Access，直接存储器访问。  
它的核心思想是：**主存和外设之间直接成块传送数据，CPU 只在开始和结束时干预较多**。

| 方式     | CPU 与外设能否并行 | 传送单位 | 谁把数据送入内存 |
| -------- | ------------------ | -------- | ---------------- |
| 程序查询 | 不能               | 字       | CPU              |
| 中断方式 | 能                 | 字       | CPU              |
| DMA      | 能                 | 块       | 外设/DMA 控制器  |

### 2. 例题分析

**例 1**  
DMA 控制方式是在谁和谁之间直接建立数据通路？  
**结论**：**主存与外设**

**例 2**  
采用 DMA 方式传送数据时，每传送一个数据通常占用什么周期？  
**结论**：常考 **总线周期**

**例 3**  
哪种 I/O 控制方式传输速度快、CPU 干预少？  
**结论**：**DMA**

### 3. 记忆技巧

- 口诀：**DMA 成块传，主存外设直接连**
- 遇到“并行工作 + 块传输”，优先 DMA

## 总线

### 1. 知识点

总线是连接多个部件的一组公共信号线。  
三大总线一定要分清：

- **数据总线 DB**：传数据，**双向**
- **地址总线 AB**：传地址，**单向**
- **控制总线 CB**：传控制和状态，整体看双向

| 总线     | 作用               | 方向     | 决定什么         |
| -------- | ------------------ | -------- | ---------------- |
| 数据总线 | 传送数据信息       | 双向     | 一次交换数据位数 |
| 地址总线 | 传送地址           | 单向     | 最大寻址能力     |
| 控制总线 | 传送控制/状态/时序 | 整体双向 | 系统控制能力     |

### 2. 例题分析

**例 1**  
地址总线宽度决定什么？  
**结论**：**最大寻址能力**

**例 2**  
数据总线是单向还是双向？  
**结论**：**双向**

### 3. 记忆技巧

- 口诀：**数据双向、地址单向、控制管全场**
