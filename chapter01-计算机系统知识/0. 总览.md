# 章节笔记

## 总记忆表

| 模块      | 最常考的记忆句                                        |
| --------- | ----------------------------------------------------- |
| 运算器    | **ALU 运算，AC 暂存结果**                             |
| 控制器    | **控制器发控制信号，IR 存指令，PC 指向下一条**        |
| 内存编址  | **$\text{容量} = \text{大地址} - \text{小地址} + 1$** |
| 补码      | **$\text{负数补码} = \text{反码} + 1$**               |
| 浮点数    | **范围看阶码，精度看尾数；先对阶，再运算**            |
| 寻址      | **立即最快，间接最慢**                                |
| 校验码    | **奇偶检错不纠错，海明可纠错，CRC 检错强**            |
| RISC/CISC | **RISC 少而规整，CISC 多而复杂**                      |
| 流水线    | **周期取最长段，吞吐率看单位时间结果数**              |
| Cache     | **内容是主存副本，映射由硬件自动完成**                |
| 中断      | **中断向量给入口地址，保存现场为返回原程序**          |
| DMA       | **主存和外设直接成块传输，CPU 少干预**                |
| 加密      | **公钥加密私钥解密；私钥签名公钥验证**                |
| 数字证书  | **CA 私钥签名，CA 公钥验证**                          |
| 可靠性    | **串联相乘，并联用 1 减全失败**                       |
