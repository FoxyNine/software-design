## 进制转换

### 1. 知识点

计算机中常用的四种进制：

| 进制     | 基数 | 数码     | 后缀  | 例子  |
| -------- | ---- | -------- | ----- | ----- |
| 二进制   | 2    | 0, 1     | B     | 1011B |
| 八进制   | 8    | 0~7      | O / Q | 265O  |
| 十进制   | 10   | 0~9      | D     | 181D  |
| 十六进制 | 16   | 0~9, A~F | H     | B5H   |

转换只有五条主线：

1. 非十进制 → 十进制：**按权展开求和**
2. 十进制 → 非十进制：整数**除基取余**，小数**乘基取整**
3. 二进制 ↔ 八进制：**3 位一组**
4. 二进制 ↔ 十六进制：**4 位一组**
5. 八进制 ↔ 十六进制：**借道二进制**，不能直接分组

关键结论：**1 字节 = 8 位 = 2 个十六进制位**。

### 2. 公式/模板

**按权展开**（非十进制 → 十进制）：

$(\text{数})_R = \sum d_i \times R^i$

小数点左边从 $R^0$ 起递增，右边从 $R^{-1}$ 起递减。

**十进制 → 非十进制**：

- 整数部分：除基取余，**逆序**排列
- 小数部分：乘基取整，**顺序**排列

**0~15 对照表（必背）**

| 十进制 | 二进制 | 八进制 | 十六进制 |
| ------ | ------ | ------ | -------- |
| 0      | 0000   | 0      | 0        |
| 1      | 0001   | 1      | 1        |
| 2      | 0010   | 2      | 2        |
| 3      | 0011   | 3      | 3        |
| 4      | 0100   | 4      | 4        |
| 5      | 0101   | 5      | 5        |
| 6      | 0110   | 6      | 6        |
| 7      | 0111   | 7      | 7        |
| 8      | 1000   | 10     | 8        |
| 9      | 1001   | 11     | 9        |
| 10     | 1010   | 12     | A        |
| 11     | 1011   | 13     | B        |
| 12     | 1100   | 14     | C        |
| 13     | 1101   | 15     | D        |
| 14     | 1110   | 16     | E        |
| 15     | 1111   | 17     | F        |

**2 的幂次表**

| $2^n$  | 值       | $2^n$   | 值        |
| ------ | -------- | ------- | --------- |
| $2^0$  | 1        | $2^8$   | 256       |
| $2^1$  | 2        | $2^9$   | 512       |
| $2^2$  | 4        | $2^{10}$ | 1024 ≈ 1K |
| $2^3$  | 8        | $2^{15}$ | 32768     |
| $2^4$  | 16       | $2^{16}$ | 65536     |
| $2^5$  | 32       | $2^{20}$ | ≈ 1M      |
| $2^6$  | 64       | $2^{30}$ | ≈ 1G      |
| $2^7$  | 128      | $2^{32}$ | ≈ 4G      |

### 3. 例题分析

**例 1**  
$(1011.01)_2$ 转十进制？  
**解法**：$1\times2^3+0\times2^2+1\times2^1+1\times2^0+0\times2^{-1}+1\times2^{-2}=8+2+1+0.25$  
**结论**：**11.25**

**例 2**  
十进制 45 转二进制？  
**解法**：除基取余倒序写。45÷2=22 余 1，22÷2=11 余 0，11÷2=5 余 1，5÷2=2 余 1，2÷2=1 余 0，1÷2=0 余 1  
**结论**：**101101B**（验算 32+8+4+1=45）

**例 3**  
0.625 转二进制？  
**解法**：乘基取整顺序写。0.625×2=1.25 取 1，0.25×2=0.5 取 0，0.5×2=1.0 取 1  
**结论**：**0.101B**

**例 4**  
10110101B 转八进制与十六进制？  
**解法**：八进制 3 位一组 → `010 110 101` → 265O；十六进制 4 位一组 → `1011 0101` → B5H  
**结论**：**265O、B5H**

**例 5**  
265O 转十六进制？  
**解法**：不能直接分组，借道二进制：265O → `010 110 101` → `1011 0101` → B5H

**易错点**

- 分组必须**从小数点向两侧**分：整数部分从右往左，小数部分从左往右，不足位补 0
- 补 0 方向：整数部分在**最左侧**补，小数部分在**最右侧**补
- 十进制小数可能**无限循环**（如 0.1），需按精度截断

### 4. 记忆技巧

- 口诀：**十转他，整数除基取余倒着写，小数乘基取整顺着写**
- 口诀：**二转八 3 位一组，二转十六 4 位一组**
- 口诀：**八转十六不直接换，借道二进制**
- 看到十六进制地址先想 $2^4=16$；看到存储容量先想 $2^{10}=1024$
- 进制转换与**补码**是两码事：补码是负数表示法，不属于进制转换

## 内存按字节编址

### 1. 知识点

按字节编址题本质是**地址差计算题**。  
只要题目没有特别说明，容量计算统一按：

**容量 = 末地址 - 首地址 + 1**

然后再根据单位换算成 B、KB、MB。

### 2. 公式/模板

$\text{容量（字节）} = \text{大地址} - \text{小地址} + 1$

换算关系：

$1\text{KB} = 1024\text{B}$

$1\text{MB} = 1024\text{KB}$

**做题模板**

1. 先把十六进制地址做减法  
2. 结果再加 1  
3. 按题意换算单位  
4. 若问芯片片数，再用“$\text{总容量} \div \text{单片容量}$”

### 3. 例题分析

**例 1**  
地址 0000A000H ～ 0000BFFFH，共有多少个存储单元？  
**解法**：BFFFH - A000H + 1 = 2000H = 8192B = 8KB  
**结论**：8KB

**例 2**  
内存按字节编址，从 A1000H 到 B13FFH 的区域容量是多少？  
**模板**：B13FFH - A1000H + 1，再转 KB

**易错点**

- 忘记 **+1**
- 十六进制减法算完后没有换成十进制/KB

### 4. 记忆技巧

- 口诀：**大减小，再加 1**
- 不要被地址长得吓到，十六进制只是写法不同，本质还是区间长度

## 原码、反码、补码、移码

### 1. 知识点

这是计算机系统高频必考点。  
默认约定：**最高位为符号位，0 正 1 负**。

- **原码**：符号位 + 绝对值
- **反码**：正数不变；负数除符号位外按位取反
- **补码**：正数不变；负数 = 反码 + 1
- **移码**：在补码基础上对符号位取反

补码最重要，因为计算机通常用补码做运算。

| 码制 | 正数           | 负数            | 0 的特点        | 高频结论         |
| ---- | -------------- | --------------- | --------------- | ---------------- |
| 原码 | 与真值接近     | 符号位 + 绝对值 | +0 与 -0 不同   | 直观但不利于运算 |
| 反码 | 与原码相同     | 绝对值按位取反  | +0 与 -0 不同   | 是补码的中间步骤 |
| 补码 | 与原码相同     | 反码 + 1        | 正负 0 编码相同 | **计算机常用**   |
| 移码 | 补码符号位取反 | 补码符号位取反  | 正负 0 编码相同 | 常用于阶码       |

### 2. 公式/模板

$\text{负数补码} = \text{负数反码} + 1$

$\text{补码再求补码} = \text{原码}$

### 3. 例题分析

**例 1**  
16 位补码 FFFFH 表示的十进制数是多少？  
**思路**：全 1 的补码就是 **-1**  
**结论**：-1

**例 2**  
为什么计算机采用补码进行运算？  
**答案要点**：**可以简化运算部件设计**

**例 3**  
若某计算机采用 8 位补码表示整数，哪些运算会溢出？  
**思路**：8 位补码整数范围是 **-128 ~ 127**，结果超出即溢出

### 4. 记忆技巧

- 口诀：**负数看补码，先反后加一**
- 判溢出先看范围，不要一上来就硬算二进制

## 浮点数

### 1. 知识点

浮点数核心只考三件事：

1. **表示形式**：$N = \text{尾数} \times \text{基数}^{\text{指数}}$  
2. **范围由阶码决定，精度由尾数决定**  
3. **浮点数相加先对阶：小阶向大阶对齐，尾数右移**

| 概念         | 结论                          |
| ------------ | ----------------------------- |
| 范围         | 看阶码位数                    |
| 精度         | 看尾数位数                    |
| 对阶原则     | 小阶向大阶对齐                |
| 尾数移动方向 | 右移                          |
| 规格化       | 尾数绝对值通常限制在 [0.5, 1) |

### 2. 公式/模板

$\text{浮点数运算步骤：对阶} \rightarrow \text{尾数运算} \rightarrow \text{结果规格化}$

增加阶码位数：范围增大、精度降低。  

增加尾数位数：精度提高、范围不一定扩大。

### 3. 例题分析

**例 1**  
两个浮点数相加，第一步做什么？  
**结论**：**先统一阶码**

**例 2**  
增加指数部分 E 的位数、减少尾数 M 的位数，会怎样？  
**结论**：**表示范围扩大，精度下降**

**例 3**  
浮点数表示中，哪一部分决定数值范围？  
**结论**：**阶码**

### 4. 记忆技巧

- 记忆句：**范围看阶，精度看尾；先对阶，再动尾**
- 对阶时不是大阶去找小阶，而是 **小阶向大阶靠拢**

## 寻址方式

### 1. 知识点

寻址题本质上考：**操作数在哪里**。  
最常见的 7 种：

- 立即寻址：操作数就在指令中
- 直接寻址：指令给出操作数所在内存地址
- 寄存器寻址：操作数在寄存器中
- 寄存器间接寻址：寄存器里放的是内存地址
- 间接寻址：指令给出的是地址的地址
- 相对寻址：当前地址 + 偏移量
- 变址寻址：变址寄存器内容 + 偏移量

| 寻址方式       | 操作数位置             | 速度特点 |
| -------------- | ---------------------- | -------- |
| 立即寻址       | 指令内部               | 最快     |
| 寄存器寻址     | 寄存器                 | 很快     |
| 直接寻址       | 内存单元               | 次之     |
| 寄存器间接寻址 | 内存，地址在寄存器     | 更慢     |
| 间接寻址       | 内存，且要再找一次地址 | 最慢     |

### 2. 例题分析

**例 1**  
在机器指令地址字段中，直接指出操作数本身的寻址方式称为？  
**结论**：**立即寻址**

**例 2**  
立即寻址、寄存器寻址、直接寻址三者速度比较？  
**结论**：**立即最快，寄存器次之，直接最慢**

### 3. 记忆技巧

- 判断关键：题目问的是“给出操作数本身”，还是“给出地址”
- 一句话：**立即最快，间接最慢**
