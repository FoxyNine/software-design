## 图的基本概念

### 1. 知识点

| 项目       | 无向图             | 有向图                |
| ---------- | ------------------ | --------------------- |
| 边         | 无方向             | 有方向（弧）          |
| 顶点度数和 | $2e$               | 入度和 = 出度和 = $e$ |
| 完全图边数 | $\frac{n(n-1)}{2}$ | $n(n-1)$              |
| 连通概念   | 连通图             | 强连通图              |

### 2. 公式/模板

无向完全图边数：

$$
\frac{n(n-1)}{2}
$$

有向完全图弧数：

$$
n(n-1)
$$

### 3. 例题分析

**例 1**
无向图所有顶点的度数之和为什么一定是偶数？

**思路**
因为每条边都给两个端点各贡献 1 度，所以总度数和是 $2e$。

**结论**
无向图顶点度数和一定为偶数。
**正确选项**：写“等于 $2e$”的选项。

------

**例 2**
连通图和强连通图有什么区别？

**思路**
连通图针对无向图；强连通图针对有向图。
不要把两个概念混用。

**结论**
无向图说连通，有向图说强连通。
**正确选项**：按图类型选。

### 4. 记忆技巧

- **无向看连通，有向看强连通**
- **无向图总度数 = 2 倍边数**

## 邻接矩阵与邻接表

### 1. 知识点

| 存储方式 | 特点                         | 适用图 | 高频考点       |
| -------- | ---------------------------- | ------ | -------------- |
| 邻接矩阵 | 结构直观、判断两点有无边方便 | 稠密图 | 对称、行列意义 |
| 邻接表   | 节省空间                     | 稀疏图 | 边数与表结点数 |

### 2. 公式/模板

无向图采用邻接矩阵时：

- 矩阵是对称的
- 顶点度数 = 该行（列）非零元素个数

有向图采用邻接矩阵时：

- 行非零个数 = 出度
- 列非零个数 = 入度

### 3. 例题分析

**例 1**
无向图的邻接矩阵有什么典型特征？

**思路**
边没有方向，因此 $A[i][j]=A[j][i]$。

**结论**
无向图邻接矩阵是对称矩阵。
**正确选项**：写“对称矩阵”的那一项。

------

**例 2**
在有向图邻接矩阵中，顶点 $i$ 的出度和入度分别怎么看？

**思路**
从 $i$ 出发的弧写在第 $i$ 行；指向 $i$ 的弧落在第 $i$ 列。

**结论**
出度看行，入度看列。
**正确选项**：行出列入。

### 4. 记忆技巧

- **稠密图看矩阵，稀疏图看链表**
- **有向图：行出列入**
- **无向矩阵必对称**

## 图的遍历

### 1. 知识点

| 遍历 | 思想               | 辅助结构 | 高频考法         |
| ---- | ------------------ | -------- | ---------------- |
| BFS  | 一层一层扩展       | 队列     | “广度优先用什么” |
| DFS  | 一条路走到底再回退 | 栈或递归 | “深度优先用什么” |

### 2. 公式/模板

在邻接表存储下，遍历复杂度通常为：

$$
O(n+e)
$$

在邻接矩阵存储下，遍历复杂度通常为：

$$
O(n^2)
$$

### 3. 例题分析

**例 1**
广度优先遍历为什么使用队列？

**思路**
因为 BFS 必须先处理当前层较早发现的顶点，再处理较晚发现的顶点，正符合先进先出。

**结论**
BFS 用队列。
**正确选项**：队列。

------

**例 2**
深度优先遍历可以如何实现？

**思路**
DFS 的本质是不断向下深入，天然对应递归调用栈，也可用显式栈实现。

**结论**
可用栈或递归。
**正确选项**：写“栈 / 递归”的那一项。

### 4. 记忆技巧

- **广搜队列，深搜栈**
- **图遍历复杂度和存储方式有关**

## 最小生成树

### 1. 知识点

| 算法               | 思想              | 更适合  | 高频标签  |
| ---------------- | --------------- | ---- | ----- |
| Prim(普利姆算法)      | 从一个顶点出发，不断扩充顶点集 | 稠密图  | 选点扩张  |
| Kruskal(克鲁斯卡尔算法) | 按边权从小到大选边，避免成环  | 稀疏图  | 选边避环  |
| 本质策略             | 贪心              | 两者相同 | 高频选择题 |

### 2. 公式/模板

最小生成树只适用于：

- **连通无向图**

生成树边数固定为：

$$
n-1
$$

### 3. 例题分析

**例 1**
Prim 和 Kruskal 都属于什么算法设计策略？

**思路**
两者都在每一步做当前最优选择。

**结论**
都属于贪心算法。
**正确选项**：贪心法。

------

**例 2**
若图较稠密，更适合 Prim 还是 Kruskal？

**思路**
Prim 更适合稠密图；Kruskal 更适合稀疏图。

**结论**
图较稠密时选 Prim。
**正确选项**：Prim。

### 4. 记忆技巧

- **点扩 Prim，边扩 Kruskal**
- **稠密 Prim，稀疏 Kruskal**
- **MST 题一见就是贪心**

## 拓扑排序

### 1. 知识点

| 项目     | 结论                         | 高频考法           |
| -------- | ---------------------------- | ------------------ |
| 适用图   | 有向无环图（DAG）            | “拓扑序列存在条件” |
| 基本过程 | 反复选入度为 0 的顶点输出    | 过程题             |
| 判环依据 | 若无法输出全部顶点，图中有环 | 判断题             |

### 2. 公式/模板

拓扑排序流程：

1. 统计各顶点入度
2. 选择入度为 0 的顶点输出
3. 删除相关弧，更新入度
4. 重复直到结束

### 3. 例题分析

**例 1**
拓扑排序只适用于哪类图？

**思路**
若图中有环，就无法排出先后顺序。

**结论**
只适用于有向无环图。
**正确选项**：DAG。

------

**例 2**
在 DAG 的拓扑序列中，若顶点 $u$ 在 $v$ 之前，则一定能推出什么？

**思路**
若存在从 $v$ 到 $u$ 的路径，就会与顺序矛盾并形成环式约束。

**结论**
一定不存在从 $v$ 到 $u$ 的路径。
**正确选项**：写“不存在 $v$ 到 $u$ 路径”的选项。

### 4. 记忆技巧

- **拓扑排序先找入度 0**
- **排不完就有环**
- **只属于 DAG**
