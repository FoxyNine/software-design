# 二、复习建议

| 轮次    | 目标     | 建议做法                                                     | 关注重点                                   |
| ------- | -------- | ------------------------------------------------------------ | ------------------------------------------ |
| 第 1 轮 | 建骨架   | 先看“当前整理范围”和“总记忆表”，把第三章七大块串起来         | 复杂度、线性表、树、图                     |
| 第 2 轮 | 学概念   | 按知识点表格逐节背，自己口述“是什么、有什么特点、怎么考”     | 顺序表与链表、栈与队列、BST 与 AVL         |
| 第 3 轮 | 学会做题 | 按“题眼—知识点—答案方向”刷原题，重点练复杂度、数组地址、遍历、排序 | 复杂度、数组地址、图遍历、排序稳定性       |
| 第 4 轮 | 冲刺提分 | 只看口诀、公式、易混点、原题答案，快速滚动复盘               | 哈夫曼树、拓扑排序、二分前提、快排最坏情况 |

# 三、章节笔记

## 总记忆表

| 模块         | 记忆句                                 |
| ------------ | -------------------------------------- |
| 时间复杂度   | **只留最高阶，常数系数都不看**         |
| 顺序表与链表 | **查找看顺序表，插删看链表**           |
| 栈           | **后进先出，只看栈顶**                 |
| 队列         | **先进先出，头出尾进**                 |
| 串           | **子串必须连续，空格也算字符**         |
| 数组地址     | **先看下标起点，再看行优先还是列优先** |
| 稀疏矩阵     | **非零很少，三元组最常考**             |
| 树性质       | **总结点 = 总度数 + 1**                |
| 二叉树       | **叶子 = 双分支 + 1**                  |
| 构造二叉树   | **必须有中序**                         |
| 哈夫曼树     | **权值大靠根，带权路径和最小**         |
| 图存储       | **稠密图矩阵，稀疏图链表**             |
| BFS / DFS    | **广搜队列，深搜栈或递归**             |
| 最小生成树   | **Prim 选点扩，Kruskal 选边避环**      |
| 拓扑排序     | **只属于有向无环图**                   |
| 二分查找     | **有序 + 顺序存储，两个条件缺一不可**  |
| 排序稳定性   | **稳：插冒归基；不稳：选希堆快**       |
