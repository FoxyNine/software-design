## 树

### 1. 知识点

| 性质    | 结论                                 | 常考形式      |
| ----- | ---------------------------------- | --------- |
| 树性质 1 | 树中结点总数 = 所有结点度数之和 + 1              | 已知度数求结点数  |
| 树层结点数 | 度为 $m$ 的树，第 $i$ 层最多有 $m^{i-1}$ 个结点 | 已知层数求最多结点 |
| 树高度   | 高度越高，最多结点数越大                       | 反推最小高度    |

### 2. 公式/模板

总结点数：

$$
n=\sum 度数+1
$$

度为 $m$ 的树，第 $i$ 层最多结点数：

$$
m^{i-1}
$$

### 3. 例题分析

**例 1**
树中所有结点的度数之和为 19，则结点总数是多少？

**思路**
直接套树性质 1。

**结论**
总结点数是 $19+1=20$。
**正确选项**：20。

------

**例 2**
度为 3 的树，第 4 层最多有多少个结点？

**思路**
直接套公式：

$$
3^{4-1}=3^3=27
$$

**结论**
第 4 层最多 27 个结点。
**正确选项**：27。

### 4. 记忆技巧

- **树的总结点永远比总度数多 1**
- **树层题：度数当底，层号减 1 当指数**

------

## 二叉树

### 1. 知识点

| 性质                          | 结论                       | 高频考点 |
| ----------------------------- | -------------------------- | -------- |
| 第 $i$ 层最多结点数           | $2^{i-1}$                  | 分层计算 |
| 高度为 $h$ 的二叉树最多结点数 | $2^h-1$                    | 高度题   |
| 度为 0 的结点数               | $n_0=n_2+1$                | 叶子数题 |
| 完全二叉树高度                | $\lfloor\log_2 n\rfloor+1$ | 编号题   |

### 2. 公式/模板

$$
n_0=n_2+1
$$

$$
\text{完全二叉树高度}=\lfloor\log_2 n\rfloor+1
$$

### 3. 例题分析

**例 1**
若某二叉树中度为 2 的结点数为 7，则叶子结点数是多少？

**思路**
先抓题眼：叶子和双分支结点关系。
直接套公式：

$$
n_0=n_2+1=7+1=8
$$

**结论**
叶子结点数为 8。
**正确选项**：8。

------

**例 2**
高度为 5 的二叉树最多有多少个结点？

**思路**
直接套上界公式：

$$
2^5-1=31
$$

**结论**
最多 31 个结点。
**正确选项**：31。

### 4. 记忆技巧

- **层数公式和叶子公式是二叉树两大高频**
- **二叉树上界题，几乎都能直接套公式**

------

## 完全二叉树

### 1. 知识点

| 项目                  | 结论                           |
| --------------------- | ------------------------------ |
| 顺序存储编号从 1 开始 | 左孩子是 $2i$，右孩子是 $2i+1$ |
| 双亲结点              | 是 $\lfloor i/2 \rfloor$       |
| 最后一层              | 只可能连续出现在最左边         |

### 2. 公式/模板

编号从 1 开始时：

$$
left(i)=2i
$$

$$
right(i)=2i+1
$$

$$
parent(i)=\lfloor i/2 \rfloor
$$

### 3. 例题分析

**例 1**
完全二叉树中，编号为 9 的结点，其双亲编号是多少？

**思路**
直接套：

$$
\lfloor 9/2 \rfloor=4
$$

**结论**
双亲编号为 4。
**正确选项**：4。

------

**例 2**
为什么顺序存储特别适合完全二叉树？

**思路**
因为完全二叉树编号连续，不会浪费太多位置。
若是普通稀疏二叉树，顺序存储会浪费很多空位。

**结论**
完全二叉树优先顺序存储。
**正确选项**：写“顺序存储适合完全二叉树”的选项。

### 4. 记忆技巧

- **左 $2i$，右 $2i+1$，父亲是 $\lfloor i/2\rfloor$**
- **顺序存储最配完全二叉树**

------

## 二叉树遍历

### 1. 知识点

| 遍历方式 | 顺序               | 高频题型             |
| -------- | ------------------ | -------------------- |
| 先序遍历 | 根—左—右           | 已知先序 + 中序构树  |
| 中序遍历 | 左—根—右           | BST 中序有序         |
| 后序遍历 | 左—右—根           | 后缀表达式、析构顺序 |
| 层序遍历 | 从上到下、从左到右 | 队列                 |

### 2. 公式/模板

构造二叉树时，若要唯一确定，一般必须包含：

- 中序 + 先序，或
- 中序 + 后序

### 3. 例题分析

**例 1**
通过序列构造二叉树，哪类序列最关键？

**思路**
只有中序序列能把左右子树边界切开。
没有中序，很多树形无法唯一确定。

**结论**
必须有中序序列。
**正确选项**：写“必须有中序”的选项。

------

**例 2**
层序遍历最适合用什么辅助结构？

**思路**
层序遍历是一层一层出队，再把下一层孩子入队。

**结论**
应使用队列。
**正确选项**：队列。

### 4. 记忆技巧

- **先根先序，中根中序，后根后序**
- **构树必须有中序**
- **层序遍历靠队列**

------

## 线索二叉树

### 1. 知识点

| 项目       | 含义                           |
| ---------- | ------------------------------ |
| 线索化思想 | 利用空指针域存放遍历前驱或后继 |
| 作用       | 提高遍历效率，减少回溯         |
| 分类       | 先序线索、中序线索、后序线索   |

### 2. 公式/模板

线索二叉树本质不是新树种，而是：

- **原二叉树结构 + 对空指针的再利用**

### 3. 例题分析

**例 1**
线索二叉树为什么存在？

**思路**
普通链式二叉树中大量空指针被浪费。
线索化就是把这些空位利用起来，存放遍历关系。

**结论**
为了利用空指针域，提高遍历效率。
**正确选项**：写“利用空指针存前驱/后继”的选项。

------

**例 2**
中序线索二叉树最常对应什么信息？

**思路**
中序线索化后，空指针常用来指向中序遍历下的前驱和后继。

**结论**
中序前驱、中序后继。
**正确选项**：写“中序前驱/后继”的选项。

### 4. 记忆技巧

- **线索不是多长出结点，而是空指针不浪费**
- **中序线索最常考**

------

## 哈夫曼树

### 1. 知识点

| 项目   | 结论                        | 高频题眼     |
| ---- | ------------------------- | -------- |
| 构造原则 | 每次取权值最小的两个结点合并            | “构造过程”   |
| 目标   | 带权路径长度最小                  | “最优二叉树”  |
| 结点度数 | 只有 0 和 2，没有 1             | “树的结构性质” |
| 总结点数 | 有 $n$ 个叶子结点时，总结点数为 $2n-1$ | “结点数”    |

### 2. 公式/模板

若有 $n$ 个叶子结点，则哈夫曼树总结点数为：

$$
2n-1
$$

### 3. 例题分析

**例 1**
哈夫曼树中，权值大的结点离根近还是远？

**思路**
为了让带权路径长度最小，权值大的结点应该走更短路径。

**结论**
权值大的结点更靠近根。
**正确选项**：写“权值越大离根越近”的选项。

------

**例 2**
用 $n$ 个权值构造哈夫曼树，总结点数是多少？

**思路**
哈夫曼树是满二叉结构的一种典型，内部结点数比叶子结点少 1。

**结论**
总结点数为 $2n-1$。
**正确选项**：$2n-1$。

### 4. 记忆技巧

- **大权近根，小权远根**
- **哈夫曼树没有度为 1 的结点**
- **叶子 $n$ 个，总结点 $2n-1$**

------

## 二叉排序树与平衡二叉树

### 1. 知识点

| 结构           | 核心性质                             | 高频考点     |
| -------------- | ------------------------------------ | ------------ |
| 二叉排序树 BST | 左子树关键字 < 根 < 右子树关键字     | 中序遍历有序 |
| 平衡二叉树 AVL | 任一结点左右子树高度差绝对值不超过 1 | 是否平衡     |

### 2. 公式/模板

BST 中序遍历一定得到：

$$
\text{递增有序序列}
$$

AVL 平衡条件是：

$$
|h_L-h_R|\le 1
$$

### 3. 例题分析

**例 1**
为什么二叉排序树中序遍历一定有序？

**思路**
中序遍历是“左—根—右”，而 BST 恰好满足左小右大。

**结论**
中序遍历得到有序序列。
**正确选项**：写“中序有序”的选项。

------

**例 2**
判断一棵树是不是 AVL，重点看什么？

**思路**
不是先看关键字大小规律，而是先看高度差。
只要某个结点左右子树高度差超过 1，就不是 AVL。

**结论**
看任一结点的左右子树高度差。
**正确选项**：写“高度差绝对值不超过 1”的选项。

### 4. 记忆技巧

- **BST 看大小，AVL 看高度差**
- **BST 中序一定有序**

## 树、森林与二叉树转换

### 1. 知识点

| 规则         | 含义                                   | 高频说法   |
| ------------ | -------------------------------------- | ---------- |
| 左孩子右兄弟 | 第一个孩子变左孩子，下一个兄弟变右孩子 | 树转二叉树 |
| 森林转二叉树 | 先每棵树各自转换，再把各树根按兄弟相连 | 森林题     |
| 二叉树还原树 | 沿左指针找孩子，沿右指针找兄弟         | 还原       |

### 2. 公式/模板

树转二叉树核心口诀：

```text
左孩子，右兄弟
```

### 3. 例题分析

**例 1**
普通树转换成二叉树时，某结点的第一个孩子在二叉树中对应什么？

**思路**
这是规则本身。

**结论**
对应左孩子。
**正确选项**：左孩子。

------

**例 2**
兄弟结点在转换后的二叉树中是什么关系？

**思路**
兄弟沿右链相连。

**结论**
对应右孩子关系。
**正确选项**：右孩子。

### 4. 记忆技巧

- **左孩子，右兄弟**
- **树和森林题不会时，先转二叉树再做**

## B-树

### 1. 知识点

| 项目     | 结论                   |
| -------- | ---------------------- |
| 阶数     | 看结点最多有多少棵子树 |
| 叶子层次 | 所有叶子在同一层       |
| 查找特点 | 多路查找，适合外存索引 |

### 2. 公式/模板

B-树阶数判断口诀：

- **先看孩子数，不先看关键字数**

### 3. 例题分析

**例 1**
给一棵 B-树图，如何判断其阶数？

**思路**
先抓题眼：结点最多能有多少棵子树。
这个最大孩子数就是阶数。

**结论**
看孩子数判断。
**正确选项**：与最大孩子数一致的那个阶数。

------

**例 2**
B-树中的所有叶子结点在同一层，这说明了什么？

**思路**
这说明 B-树查找路径长度相对均衡，性能稳定。

**结论**
B-树是平衡多路查找结构。
**正确选项**：写“所有叶子同层”的选项。

### 4. 记忆技巧

- **B-树阶数看孩子**
- **叶子同层是 B-树的稳定特征**
