顺序存储方式--顺序表
链表存储方式--单链表、循环链表、双向链表

| 性能类别     | 具体项目 | 顺序存储               | 链式存储               |
| -------- | ---- | ------------------ | ------------------ |
| **空间性能** | 存储密度 | =1，更优              | <1                 |
| **空间性能** | 容量分配 | 事先确定               | 动态改变，更优            |
| **时间性能** | 读运算  | O(1)，更优            | O(n)，最好情况为1，最坏情况为n |
| **时间性能** | 查找运算 | O(n)               | O(n)               |
| **时间性能** | 插入运算 | O(n)，最好情况为0，最坏情况为n | O(1)，更优            |
| **时间性能** | 删除运算 | O(n)               | O(1)，更优            |
