## 数组

### 1. 知识点

| 场景         | 核心要素                         | 易错点          |
| ------------ | -------------------------------- | --------------- |
| 一维数组地址 | 首地址、下标、元素长度           | 下标起点        |
| 二维数组地址 | 行列数、优先方式、元素长度       | 行优先 / 列优先 |
| 统一符号     | $LOC$ 为首地址，$L$ 为元素字节数 | 符号混乱        |

### 2. 公式/模板

一维数组，下标从 0 开始：

$$
LOC(A[i])=LOC(A[0])+i\times L
$$

一维数组，下标从 1 开始：

$$
LOC(A[i])=LOC(A[1])+(i-1)\times L
$$

二维数组按行优先、下标从 0 开始：

$$
LOC(A[i][j])=LOC(A[0][0])+(i\times M+j)\times L
$$

二维数组按行优先、下标从 1 开始：

$$
LOC(A[i][j])=LOC(A[1][1])+((i-1)\times M+(j-1))\times L
$$

二维数组按列优先、下标从 0 开始：

$$
LOC(A[i][j])=LOC(A[0][0])+(j\times N+i)\times L
$$

二维数组按列优先、下标从 1 开始：

$$
LOC(A[i][j])=LOC(A[1][1])+((j-1)\times N+(i-1))\times L
$$

### 3. 例题分析

**例 1**
已知二维数组按行优先存储，元素长度为 $L$，求 $A[i][j]$ 地址。

**思路**
先抓题眼：行优先。
行优先的偏移量一定先“跨整行”，所以先乘列数 $M$。

**结论**
偏移量是“前面整行元素个数 + 本行前面元素个数”。
**正确选项**：凡是先乘列数的表达式。

------

**例 2**
为什么数组地址题经常做错？

**思路**
不是公式不会，而是容易漏掉：

1. 下标从 0 还是 1 开始；
2. 行优先还是列优先；
3. 元素大小是否为 1。

**结论**
地址题必须先判“三件事”：起点、优先方式、元素长度。
**正确选项**：按完整公式代入的那一项。

### 4. 记忆技巧

- **行优先先乘列数，列优先先乘行数**
- **下标从 1 开始就整体减 1**
- **地址题先列公式，不要直接心算**

## 矩阵

### 1. 知识点

| 矩阵类型   | 特征                                     | 常考存储方式           |
| ---------- | ---------------------------------------- | ---------------------- |
| 对称矩阵   | $a_{ij}=a_{ji}$                          | 只存一半 + 主对角线    |
| 三对角矩阵 | 只有主对角线及其上下各一条对角线可能非零 | 压缩一维数组           |
| 稀疏矩阵   | 非零元素很少                             | 三元组顺序表、十字链表 |

### 2. 公式/模板

对称矩阵压缩存储的核心不是死背全部下标公式，而是先记原则：

- 上三角和下三角信息重复，只需存一半
- 主对角线必须保留

### 3. 例题分析

**例 1**
对称矩阵为什么可以压缩存储？

**思路**
因为关于主对角线对称，一半元素可由另一半推出。

**结论**
只需存下三角区（或上三角区）加主对角线。
**正确选项**：写“只存一半”的那一项。

------

**例 2**
稀疏矩阵最常用压缩方式是什么？

**思路**
稀疏矩阵大多数位置为 0，真正值得存的是“非零元素的行、列、值”。

**结论**
三元组顺序表和十字链表。
**正确选项**：凡是写这两个结构的选项。

### 4. 记忆技巧

- **对称矩阵存一半**
- **稀疏矩阵只存非零**
- **三元组 = 行 + 列 + 值**

## 广义表

### 1. 知识点

| 概念      | 含义                   | 高频考法        |
| --------- | ---------------------- | --------------- |
| 原子      | 不可再分的数据元素     | 判断元素类型    |
| 子表      | 元素本身仍是表         | `head` / `tail` |
| `head(L)` | 取表头                 | 拿第一个元素    |
| `tail(L)` | 取去掉表头后的剩余部分 | 多层嵌套取元素  |

### 2. 公式/模板

广义表题模板：

1. 想拿第一项：`head`
2. 想去掉第一项：`tail`
3. 想拿深层元素：一层一层套用

### 3. 例题分析

**例 1**
若 $L=((x,y,z),a,(u,t,w))$，怎样取出原子项 $y$？

**思路(==head 拿头，tail 去头==)**
先抓题眼：$y$ 在第一项 `(x,y,z)` 里面。
先取第一项：`head(L)`。
再在 `(x,y,z)` 中去掉 `x`：`tail(head(L))`。
再取头得到 `y`。

**结论**
应写为：

```text
head(tail(head(L)))
```

**正确选项**：对应这条表达式的选项。

------

**例 2**
为什么广义表题容易错？

**思路**
最常见错误是把 `head` 和 `tail` 反了。
`head` 是拿第一项，不是“拿第一个原子”；`tail` 是去掉表头后的“剩余表”。

**结论**
做题时先在纸上画层级。
**正确选项**：符合层级剥离顺序的那一项。

### 4. 记忆技巧

- **head 拿头，tail 去头**
- **广义表题像剥洋葱，一层一层来**
