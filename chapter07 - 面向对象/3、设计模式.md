# 设计模式总览

软考中级《软件设计师》的设计模式部分采用 **GoF 23 种**，按创建型、结构型、行为型三类划分。

- 上午题：考分类归属与意图匹配
- 下午第 6 题（Java / C++ 二选一）：考类图 + 代码填空

## 三类速记总表

| 类别 | 数量 | 口诀 | 关注点 |
|---|---|---|---|
| 创建型 | 5 | 工抽建原单 | 对象的**创建** |
| 结构型 | 7 | 适桥组装外享代 | 类/对象的**组合** |
| 行为型 | 11 | 责命解迭中，备观状策模访 | 对象间的**交互与职责分配** |

# 一、创建型（5 种）——管"怎么生对象"

**1. 单例 Singleton** — 保证一个类仅有一个实例，并提供全局访问点。
速记：**一个就够**。例：配置管理器、数据库连接池、日志器。

**2. 工厂方法 Factory Method** — 定义创建对象的接口，让子类决定实例化哪个类。
速记：**子类说了算**。例：Oracle / SQLServer 连接对象的创建。

**3. 抽象工厂 Abstract Factory** — 创建一系列相关对象族，无须指定具体类。
速记：**一套一起换**。例：Win / Mac 的「按钮 + 文本框 + 滚动条」整套 UI 工厂。

**4. 建造者 Builder** — 将复杂对象的构建与表示分离，同一构建过程可产生不同表示。
速记：**分步拼装**。例：同一份数据导出 Excel / PDF / Word；SQL 语句构造器。

**5. 原型 Prototype** — 用原型实例指定创建的种类，通过拷贝创建新对象。
速记：**照抄一份**。例：Excel 单元格格式刷；复杂对象深拷贝。

> 口诀：**工抽建原单**（工厂方法、抽象工厂、建造者、原型、单例）

# 二、结构型（7 种）——管"怎么拼对象"

**6. 适配器 Adapter** — 将不兼容的接口转换为客户期望的接口。
速记：**转接头**。例：电源转接头；旧 DAL 接口适配新 BLL 接口。

**7. 桥接 Bridge** — 将抽象部分与实现部分分离，使二者可独立变化。
速记：**两个维度各自扩展**。例：形状 × 颜色的组合；图形 × 平台。

**8. 组合 Composite** — 组合成树形结构表示「部分-整体」，客户一致对待单个与组合对象。
速记：**叶子和树枝一个样**。例：文件 / 文件夹；部门组织树；BOM 树；菜单树。

**9. 装饰器 Decorator** — 动态给对象添加职责，比继承更灵活。
速记：**一层层包**。例：Java IO 流；咖啡加糖加奶；控件加边框和滚动条。

**10. 外观 Facade** — 为子系统提供一致的简化接口。
速记：**一键启动**。例：按电源键开机；Service 层封装多次 DAO 调用。

**11. 享元 Flyweight** — 共享细粒度对象，支持大量对象。
速记：**共享复用**。例：文本编辑器的字符对象；围棋棋子；字符串常量池。

**12. 代理 Proxy** — 为其他对象提供代理以控制访问。
速记：**代你办事**。例：图片延迟加载（虚拟代理）、权限校验（保护代理）、远程代理。

> 口诀：**适桥组，装外享代**（适配器、桥接、组合 / 装饰器、外观、享元、代理）

# 三、行为型（11 种）——管"怎么交互"

**13. 职责链 Chain of Responsibility** — 请求沿链传递，直到被处理。
速记：**逐级上报**。例：请假 / 采购单签核流；Web 中间件；异常处理。

**14. 命令 Command** — 把请求封装为对象，支持参数化、排队、日志、撤销。
速记：**把操作变成对象**。例：撤销 / 重做；菜单按钮；事务日志；宏录制。

**15. 解释器 Interpreter** — 给定语言定义文法表示及对应解释器。
速记：**自定义小语言**。例：正则表达式；SQL 解析；公式计算器。

**16. 迭代器 Iterator** — 顺序访问聚合元素而不暴露内部结构。
速记：**统一遍历**。例：foreach；集合遍历。

**17. 中介者 Mediator** — 用中介对象封装对象间交互，降低耦合。
速记：**都找中间人**。例：聊天室；对话框控件协调；MVC 的 Controller。

**18. 备忘录 Memento** — 不破坏封装地捕获并恢复对象内部状态。
速记：**存档读档**。例：撤销操作；游戏存档；事务回滚快照。

**19. 观察者 Observer** — 状态变化时自动通知所有依赖者（发布-订阅）。
速记：**一变全知道**。例：Excel 数据改图表跟着变；事件监听；MES 报警推送。

**20. 状态 State** — 内部状态改变时改变对象行为。
速记：**状态决定行为**。例：订单流转（待付款 → 已付款 → 已发货）；TCP 连接状态。

**21. 策略 Strategy** — 定义一族算法并封装，使它们可互换。
速记：**算法可换插**。例：不同排序算法；不同折扣 / 计价规则；不同支付方式。

**22. 模板方法 Template Method** — 父类定义算法骨架，子类实现某些步骤。
速记：**父定框子填空**。例：JDBC 模板；并发请求处理流程；报表生成骨架。

**23. 访问者 Visitor** — 不改变元素类的前提下，定义作用于其上的新操作。
速记：**外挂新操作**。例：编译器 AST 遍历；同一对象结构导出多种格式。

> 口诀：**责命解迭中，备观状策模访**
> （职责链、命令、解释器、迭代器、中介者 / 备忘录、观察者、状态、策略、模板方法、访问者）

# 四、考试要点

## 上午题常考

- **分类归属**：给出模式名，问属于哪一类。
  易错点：**桥接**是结构型不是行为型，**建造者**是创建型不是结构型。
- **意图匹配**：给出描述选模式。

## 下午第 6 题高频模式（类图 + 代码填空）

Observer、Strategy、Factory Method、Singleton、Adapter、Composite、Decorator、State、Visitor、Template Method、Command

## 答题技巧：先看类图关系定模式

| 类图特征 | 对应模式 |
|---|---|
| 抽象父类 + 多个平行子类，行为各不相同 | Strategy / State |
| 父类骨架调子类方法（`this.xxx()`） | Template Method |
| List / Vector 存一堆兄弟接口 | Observer / Composite / Chain of Responsibility |
| 继承同一接口且持有同接口成员 | Decorator / Proxy |
