2、最优二叉树（哈夫曼树）
基本概念：
叶子结点的路径长度：结点到根的分支线数量
树的路径长度：所有叶子结点路径长度之和
权：叶子结点的数值
叶子结点的带权路径长度：权重 * 路径
树的带权路径长度(树的代价)：所有叶子结点带权路径之和


### 一、定义

哈夫曼树（Huffman Tree）= 给定 n 个带权叶子结点构造出的 **WPL 最小的二叉树**，又称**最优二叉树**。

注意区分两个"路径长度"：
- 树的路径长度：所有**叶子**到根的路径长度之和（不看权）
- 树的带权路径长度 WPL = Σ wi × li（li 为第 i 个叶子的路径长度，根为第 1 层时 li = 层数 − 1）


### 二、构造算法（贪心）

1. 把 n 个权值看成 n 棵只有根结点的森林
2. 从森林中选出**权值最小的两棵**树，合并成一棵新树，新根权值 = 两子树根权值之和
3. 重复步骤 2，直到森林只剩一棵树

核心：每次挑最小的两个 —— 权值越小埋得越深，对 WPL 贡献越小。

**构造例题**：权值集合 A=2, B=4, C=7, D=5

| 步骤 | 森林中权值（排序后） | 合并 | 新结点 |
|:----:|--------------------|------|--------|
| 初 | **2, 4**, 5, 7 | 2+4 | 6 |
| 1 | **5, 6**, 7 | 5+6 | 11 |
| 2 | **7, 11** | 7+11 | 18 |
| 结束 | 18（一棵树） | | |

得到的哈夫曼树（左 0 右 1）：

```
            18
        0/    \1
      C(7)    11
          0/   \1
        D(5)    6
            0/   \1
          A(2)  B(4)
```

WPL = 7×1 + 5×2 + 2×3 + 4×3 = 7 + 10 + 6 + 12 = **35**

### ★ WPL 速算捷径（必背）

> **WPL = 所有合并产生的新结点权值之和**

WPL = 6 + 11 + 18 = 35 ✓

不用画树、不用数层数。原理：每个权值被合并几次就被累加几次，正好等于它的深度。


### 三、哈夫曼树的性质（设叶子数 n ≥ 2）

| 性质 | 说明 |
|------|------|
| **总结点数 = 2n − 1** | n 个叶子 + 合并产生的 n−1 个新结点 |
| **没有度为 1 的结点** | 每次合并必产生两个孩子，内部结点度都是 2 |
| 度为 2 的结点数 = n − 1 | 由上两条推出 |
| **权值越大的叶子离根越近** | 贪心的必然结果 |
| **权值最小的两个结点一定是兄弟** | 第一次合并的产物 |
| 树形**不唯一** | 左右子树可交换、相同权值可选不同组合 |
| 但 **WPL 唯一** | 无论怎么构造，最小 WPL 相同 |
| 子树也是哈夫曼树 | 最优子结构，贪心可行的依据 |
| 最长编码 ≤ n − 1 | 权值近似斐波那契分布时树最"斜" |

常考：n = 100 个叶子的哈夫曼树 → 总结点 199，内部结点 99，度为 1 的结点 **0** 个。


### 四、哈夫曼编码（最高频应用）

**编码方式**：从根到叶子的路径，左分支记 0、右分支记 1。

因为所有字符都住在**叶子**上，任一编码都不可能是另一编码的前缀 —— 这就是**前缀码**，保证译码唯一可分、无需分隔符、无歧义。

沿用上例：
```
            18
        0/    \1
      C(7)    11
          0/   \1
        D(5)    6
            0/   \1
          A(2)  B(4)
```

| 字符 | 权（频次） | 编码 | 码长 |
|------|:---------:|------|:----:|
| C | 7 | `0` | 1 |
| D | 5 | `10` | 2 |
| A | 2 | `110` | 3 |
| B | 4 | `111` | 3 |

**关键结论：把权值当作频次时，WPL 就是编码后报文的总长度。** 最小化 WPL = 报文最短 = 压缩率最高。

**译码**：从根出发，读 0 走左、读 1 走右，**到达叶子即输出该字符并回到根**继续读。

```
密文 0101111100
0 → C ｜ 10 → D ｜ 111 → B ｜ 110 → A ｜ 0 → C
结果：CDBAC
```

**判断是否哈夫曼编码** = 判断是否前缀码：`{0,10,110,111}` ✓；`{0,01,10}` ✗（0 是 01 的前缀）。


### 五、算法实现与复杂度

```python
import heapq

def huffman_wpl(weights):
    """只求 WPL（= 各次合并结果之和），无需建树"""
    heapq.heapify(weights)              # 最小堆，堆化 O(n)
    wpl = 0
    while len(weights) > 1:
        a = heapq.heappop(weights)      # 最小
        b = heapq.heappop(weights)      # 次小
        wpl += a + b                    # ★ 累加每次合并结果
        heapq.heappush(weights, a + b)
    return wpl
```

| 指标 | 复杂度 |
|------|--------|
| 时间 | **O(n log n)**（n−1 次合并，每次 2 次 pop + 1 次 push） |
| 空间 | O(n) |
| 优化 | 双队列法（原始有序队列 + 合并结果队列，各取队头较小者）：排序 O(n log n) + 建树 O(n) |
| 权值已排序 | O(n) |


### 六、拓展：k 叉哈夫曼树

用于 k 元编码、"每次最多合并 k 个"类问题（合并果子等）。

**必须满足 (n − 1) % (k − 1) == 0**，否则先补若干**权值为 0 的虚叶子**：

```
补的个数 t = (k - 1 - (n - 1) % (k - 1)) % (k - 1)
```

原因：每次 k 叉合并使结点数减少 k−1，从 n 减到 1 需减 n−1，故 k−1 必须整除 n−1。补 0 权叶子不改变 WPL，但保证每次真能凑满 k 个，否则贪心浪费合并机会、得不到最优。


### 七、应用

- 数据压缩：DEFLATE（zip / gzip / PNG）、JPEG、MP3 的熵编码层
- 贪心算法典型题：合并果子、最优归并树
- 变长编码设计


### 八、考点速记清单

1. WPL 最小 —— 定义即考点
2. **WPL = 所有新建结点权值之和**（速算）
3. n 个叶子 → 共 **2n−1** 个结点，**度为 1 的结点数为 0**
4. 哈夫曼编码一定是**前缀码**；权大码短，权小码长
5. 树形不唯一，**WPL 唯一**
6. 权值最小的两个结点是兄弟
7. 构造时间复杂度 **O(n log n)**
8. 编码报文总长度 = WPL
