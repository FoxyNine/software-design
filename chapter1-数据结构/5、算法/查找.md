# 哈希表（散列表）
时间复杂度：平均O(1)，最坏O(n)

1. 算哈希值：h = hash(key)
2. 取模定位：index = h % tableSize
3. 到 bucket[index] 处比较，确认是不是目标 key

关键在于第 3 步：因为不同 key 可能算出同一个
index（哈希冲突），所以定位到的位置不一定就是目标，还需要在冲突结构里继续找。

两种冲突处理方式对应的查找
链地址法（拉链法）
每个槽位挂一个链表（或红黑树）。查找时先定位槽位，再沿着链表逐个比较 key。

开放寻址法
所有元素都放在数组本身，冲突了就按某个探测序列往后找空位。
